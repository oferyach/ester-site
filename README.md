# האתר הרשמי של אסתר שטרייט־וורצל

אתר עברי מלא הכולל 25 ספרים ושערים מקוריים, חיפוש וסינון, סקירה בת חמש פסקאות לכל ספר, ארכיון כתבות וביקורות, עיבודים לבמה ולמסך, פרסים והוקרה, ציר זמן ביוגרפי ותגובות קוראים ללא הרשמה.

## הפעלה מקומית

לחצו לחיצה כפולה על הקובץ `הפעלת-האתר.cmd`. האתר ייפתח בדפדפן בכתובת `http://localhost:3000`.

כדי לעצור את האתר, לחצו לחיצה כפולה על `עצירת-האתר.cmd`.

תגובות הקוראים נשמרות במסד SQLite מקומי של האתר ומוצגות לכל מחשב שנכנס לאתר ברשת המקומית. אין צורך בהרשמה, והמידע אינו נשלח לשירות חיצוני. מסד הנתונים נוצר אוטומטית בתיקיית `.wrangler` בהפעלה הראשונה.

תגובות שנשמרו בעבר בדפדפן מיובאות אוטומטית למסד הנתונים המקומי בביקור הראשון לאחר העדכון.

## עדכון תוכן

רשימת הספרים, הסקירות, הכתבות, העיבודים והפרסים נמצאת בקובץ `app/content.ts`. מבנה העמוד נמצא בקובץ `app/page.tsx`, העיצוב בקובץ `app/globals.css`, ותמונות השער המקומיות בתיקייה `public/assets/covers`.

## פריסה ב-Cloudflare

האתר מוגדר כ-Cloudflare Worker בשם `ester-site` ומחובר למסד D1 בשם `ester-comments` דרך הקישור `DB`.

לפני הפריסה הראשונה יש להחיל את סכימת מסד הנתונים:

```powershell
pnpm run db:migrate:remote
```

לאחר מכן אפשר לבנות ולפרוס ידנית:

```powershell
pnpm run deploy
```

ב-Cloudflare Workers Builds יש להגדיר את פקודת הבנייה `pnpm run build` ואת פקודת הפריסה `pnpm exec wrangler deploy --config dist/server/wrangler.json`. כל דחיפה לענף `main` תפעיל פריסה חדשה.
